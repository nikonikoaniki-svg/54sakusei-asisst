# 54字の種

54字の物語を書くための発想支援アプリです。

## 基本の流れ
1. テーマ①
2. テーマ②（任意）
3. 何が起こる？
4. それでどうなる？
5. どうする？
6. 最後にどうなる？

## ヒントの考え方
以前の800個の発想テンプレートは使用しません。
現在は、意味を理解する負荷が少ない「一般化された質問」だけを使います。

- 出来事：20問
- 展開：20問
- 行動：20問
- オチ：20問

合計80問です。

「自分で考えるヒント」は答えを出すのではなく、
考える方向だけを示すための質問です。


## 文言修正
80問すべてを再確認し、「テーマ①」「テーマ②」のように置換後に不自然になる表現を廃止しました。
